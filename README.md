One joke about office life, one line, written for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty. The program writes the joke to `/output/entry.txt` — a single line about the meeting that was called to discuss why every deadline keeps slipping, and what happened to that meeting.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

## The joke

> My manager moved the meeting about our missed deadlines to next week, then missed that one too.
